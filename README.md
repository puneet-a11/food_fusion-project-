# 🍕 Food Fusion

A responsive food ordering and customization web application built using HTML, CSS, and JavaScript.

## 🚀 Features

- 🏠 **Home Page** — Explore the Food Fusion website.
- 🍔 **Food Menu** — Browse different food categories.
- 🍕 **Build Your Pizza** — Customize pizza with your preferred toppings and ingredients.
- 🛒 **Shopping Cart** — Add, manage, and review selected items.
- ❤️ **Favorites** — Keep track of favorite food items.
- 💳 **Checkout** — Enter delivery and payment details.
- 📦 **Order Confirmation** — View order confirmation after checkout.
- 📩 **Contact Page** — Contact through the website's form.
- 📱 **Responsive Design** — Designed for different screen sizes.
